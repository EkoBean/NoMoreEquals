# tools

Offline code generators. **Neither runs at game time** — their only job is to
produce the two `// <auto-generated />` files under `NoMoreEquals/Data/`.
You only need them when the upstream OpenCC dictionary changes or when a new
game patch changes AXIS font coverage.

## The pipeline

```
OpenCC JPShinjitaiCharacters.txt
        │
        │  (1) generate_candidates.py     reverse jp→zh into zh→jp, add manual extras
        ▼
NoMoreEquals/Data/KanjiCandidates.cs      ~409 unfiltered pairs
        │
        │  (2) FontProbe                  keep pairs whose zh form is missing from
        ▼                                 AXIS_12.fdt but whose jp form is present
NoMoreEquals/Data/KanjiMap.cs             ~95 filtered pairs (fallback snapshot)
```

At runtime the plugin re-runs step 2's filter against the player's own font
whenever `UseLiveFontFilter` is on (the default), so `KanjiMap.cs` is only used
when that option is off or the font fails to load.

## 1. generate_candidates.py

Reads OpenCC's Japanese shinjitai dictionary and reverses it into Chinese →
Japanese candidates, plus a few hand-maintained extras (綠→緑, 黑→黒, 每→毎)
that the reversal does not produce.

The input is not vendored in this repo. Fetch it into the gitignored
`_tmp_opencc/` folder first:

```bash
git clone --depth 1 https://github.com/BYVoid/OpenCC.git _tmp_opencc
python tools/generate_candidates.py
```

Expected input path: `_tmp_opencc/data/dictionary/JPShinjitaiCharacters.txt`.
OpenCC data is Apache-2.0.

## 2. FontProbe

Opens the local FFXIV install via Lumina, parses `common/font/AXIS_12.fdt`, and
narrows `KanjiCandidates.cs` down to the pairs actually worth converting.

```bash
dotnet run --project tools/FontProbe
```

It locates the game automatically (XIVLauncher config → common install paths →
Steam libraries). Pass the game root explicitly if that fails:

```bash
dotnet run --project tools/FontProbe -- "C:\Path\To\FINAL FANTASY XIV - A Realm Reborn"
```

Optional second and third arguments override the output and input paths
(default: `NoMoreEquals/Data/KanjiMap.cs` and `NoMoreEquals/Data/KanjiCandidates.cs`).

> FontProbe parses the `.fdt` header by hand because it cannot reference
> Dalamud. The plugin itself uses Dalamud's `FdtReader` in
> `Services/AxisFontCoverage.cs`. Keep the two in sync if the format changes.
